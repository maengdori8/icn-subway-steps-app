이 문서는 ICN Subway Steps 앱의 공통 부품 규칙입니다. 기준은 이 폴더의 문서와 실제 Flutter 앱(C:\dev\projects\icn_subway_app)입니다. 시안 v03은 2026-10-20 상태로 고정했고, 시안과 앱이 다르면 앱과 사용자 결정(ui-validation-decisions.md)을 따릅니다.

- 색·글자·간격·모서리 값은 design-system.json의 tokens에 있습니다. 이 문서는 키 이름만 씁니다(예: primary, typography.button).

- 문구는 'English / 한국어' 순서로 적습니다.

## 1. 버튼

### 주요 버튼 (FilledButton)
- **용도:** 한 화면의 주요 행동 하나. 팁 올리기(S03), 로그인(S04), 가입하기(S07), 다시 시도(가운데 안내), 확인창의 '계속 쓰기'.
- **모양:** primary 바탕, onPrimary 글자, typography.button, radii.button, 높이 sizes.buttonHeight(52).
- **상태:** 기본 / 처리 중(S03은 'Posting… / 올리는 중…' 문구, S04는 글자 앞 작은 원형 진행 표시) / 누를 수 없음(primary 45% 바탕).
- **접근성:** 누르는 영역 48 이상. 처리 중에는 누를 수 없게 하고 글이나 진행 표시로 알린다.
- **하지 말 것:** 한 화면에 주요 버튼을 둘 두지 않는다. S02의 '다음'에 쓰지 않는다(경로색 버튼을 쓴다).

### 경로색 버튼 (RouteButton)
- **용도:** S02 '다음', 마지막 단계 'I'm on the platform / 승강장에 왔어요', 완료 화면 'Step n again / n단계 다시 보기'.
- **모양:** 경로에 따라 routeExpress 또는 routeLocal 바탕, 글자는 onRoute. 크기·모서리는 주요 버튼과 같다.
- **상태:** 기본 / 누를 수 없음(경로색 45%).
- **접근성:** 경로색 위 글자는 같은 테마의 onRoute만 쓴다(어두운 테마에서 흰 글자는 대비 미달).
- **하지 말 것:** 남색 primary와 섞지 않는다. 경로 구분을 색에만 맡기지 않는다.

### 보조 버튼 (FilledButton + ghostButtonStyle)
- **용도:** 이전, 취소(S03·S04·S07), 'Back to routes / 경로 목록으로'(완료 화면), 확인창의 '버리기'.
- **모양:** surfaceContainer 바탕, textPrimary 글자, typography.button(16), 높이 52.
- **변형·배치:** 주요 버튼과 한 줄에 둘 때 보조 : 주요 = 1 : 1.4, 간격 spacing.gutter(10). 완료 화면만 1 : 1.
- **상태:** 기본 / 누를 수 없음(첫 단계의 '이전').
- **하지 말 것:** 취소에 주요 버튼 색을 쓰지 않는다. 글자를 14로 줄이지 않는다.

### 글자 버튼 (TextButton)
- **용도:** '+ Add a tip / + 팁 등록'(로그인 전 '+ 팁 등록 (로그인)'), 'All steps / 전체 단계', 'Start over / 처음부터', 'Show n older tips / 지난 팁 n개 보기', 상태 바꾸기, 'Open this step / 이 단계 보기', S05 로그인·로그아웃, 알림 상자 안 '다시 시도'·'다시 로그인'.
- **모양:** routeLocal 글자, 14 / 700, 누르는 영역 48 × 48. 알림 상자 안에서는 그 상자의 글자색 + 밑줄.
- **상태:** 기본 / 누를 수 없음(textSecondary) / 처리 중(상태 바꾸기는 'Saving… / 저장 중…').
- **접근성:** 펼침 버튼(전체 단계, 지난 팁)은 펼침 상태를 낭독에 알린다. '처음부터'는 'Start over: 경로 이름 / 경로 이름 처음부터'(예: '직통열차 처음부터')로 읽는다.
- **하지 말 것:** 하단 고정 바 바로 위에 두지 않는다(잘못 누름).

## 2. 입력

### 입력칸 (LabeledField)
- **용도:** S03 팁 제목·정확한 위치·메모, S04 아이디·비밀번호, S07 아이디·비밀번호·비밀번호 확인.
- **모양:** 라벨(typography.label) 위 · 칸 · 아래 줄(왼쪽 오류 문구, 오른쪽 글자 수). 칸은 surface 바탕, outline 1.5 테두리, radii.input, 안쪽 여백 12. 예시 글자는 textSecondary 불투명도 1.
- **변형:** 한 줄(제목·위치·아이디·비밀번호), 여러 줄(메모 4~8줄, 넘으면 칸 안 스크롤).
- **상태:** 기본 / 초점(primary 2 테두리) / 입력 오류(errorBorder 테두리 + 칸 아래 error 13 / 500, 최대 3줄) / 읽기 전용(S03 올리는 중, surfaceContainer 바탕).
- **글자 수:** n/80, n/150. 앞뒤 공백을 뺀 뒤 유니코드 코드 포인트로 센다(서버와 같음). 넘으면 숫자가 error 색·굵게. 입력은 막지 않고 올리기 때 오류를 보인다.
- **접근성:** 보이는 라벨은 낭독에서 빼고 칸에 같은 이름을 붙인다. 오류가 나면 첫 오류 칸에 초점. 키보드 '다음'으로 다음 칸, 마지막 칸은 S03 메모 줄바꿈 / S04 '완료' = 로그인. 아이디·비밀번호는 자동 채움 힌트를 단다.
- **하지 말 것:** 오류가 났다고 다른 칸 값을 지우지 않는다. 오류를 문구로 저장하지 않는다(종류로 저장해 언어에 맞게 그린다). 칸 테두리 대비를 3:1 아래로 내리지 않는다.

### 눈 아이콘 (LabeledField suffix IconButton)
- **용도:** S04 비밀번호 보이기·숨기기. S07은 두 비밀번호 칸을 함께 보이기·숨기기.
- **위치:** 비밀번호 칸 안 오른쪽 끝. 누르는 영역 48 × 48, 색 textSecondary.
- **상태:** 숨김(visibility 아이콘) / 보임(visibility_off 아이콘).
- **접근성:** 낭독 이름은 'Show password / 비밀번호 보기'로 고정하고 눌림 상태로 알린다. 누른 뒤에도 초점은 이 버튼에 남는다.
- **하지 말 것:** 칸 밖에 따로 두지 않는다. 이름을 '보기/숨기기'로 번갈아 바꾸지 않는다.
- **현재 동작(고도화, 위젯 검사 통과·화면 대조 전):** 비밀번호를 보이게 해도 키보드 자동 완성 제안·자동 고침은 끈 채로 둔다(LabeledField secret).

## 3. S02 안내 부품

### 표지판 칩 + 역할 라벨 (SignChip)
- **용도:** 그 단계에서 볼 실제 표지판 글자.
- **모양:** 역할 라벨(typography.roleLabel, textPrimary, 대문자) 아래 남색 칩(signage 바탕, onSignage 글자, radii.sign). 칩 안: 픽토그램 26 + 한글 typography.signKo + 영어 typography.signEn.
- **변형:** 역할 라벨 'YOU ARE HERE / 현재 위치'(HERE) 또는 'LOOK FOR THIS SIGN / 이 표지판을 찾으세요'(FIND). 픽토그램 비행기·에스컬레이터·열차.
- **접근성:** 라벨과 칩을 한 덩어리로 읽는다. 한글은 한국어, 영어는 영어 목소리로 읽는다.
- **하지 말 것:** 언어를 바꿨다고 표지판 글자를 한쪽 언어로 줄이지 않는다. 칩 글자를 단계 제목(22)보다 작게 하지 않는다. 칩 글자를 말줄임으로 자르지 않는다(줄바꿈).

### 진행 표시 (StepProgress)
- **용도:** 지금 몇 단계인지.
- **모양:** 큰 숫자 typography.stepNumber '현재' + '/전체'(15, textSecondary), 단계 수만큼 막대(높이 6, 현재까지 경로색, 나머지 outline 35%), 오른쪽 '전체 단계' 글자 버튼.
- **변형:** 단계 화면 '3/5', 완료 화면 '5/5 완료'(막대 모두 채움).
- **접근성:** 숫자·막대는 낭독하지 않고 단계 제목이 'Step 3 of 5: 제목'을 읽는다.
- **하지 말 것:** 진행을 막대 색만으로 알리지 않는다(숫자 함께).

### 단계 사진 (StepPhoto)
- **용도:** 그 단계의 모습.
- **모양:** 4:3, radii.card. 아래 출처 한 줄(caption). 사진이 없으면 같은 4:3 칸에 카메라 아이콘 + 'Photo coming soon / 사진 준비 중', 칸 아래 'Use the sign and steps below. / 아래 표지판과 안내를 따라가세요.'
- **동작:** 가로로 밀면 앞뒤 단계. 마지막 단계에서 밀어도 완료 화면으로 가지 않는다.
- **넘김 모양(현재 동작(고도화, 위젯 검사 통과·화면 대조 전)):** 넘기는 동안(밀기·이전·다음 모두) 두 사진이 정육면체의 이웃한 면처럼 맞닿은 모서리를 축으로 돈다(CubePage, 최대 90°, 원근 0.001). 나가는 사진은 다음 사진 쪽 모서리, 들어오는 사진은 앞 사진 쪽 모서리가 축이고, 돌아간 면은 그만큼 어두워진다(최대 35%). 멈추면 평평하고 원래 밝기다. 동작 줄이기면 돌리지 않는다(2026-10-22 사용자 요청 D16).
- **접근성:** 대체 문구는 지금 언어의 표지판 이름. 사진 없는 칸은 글로 읽힌다.
- **하지 말 것:** 사진을 테마에 따라 어둡게 바꾸지 않는다(넘기는 동안의 그림자만 예외). 사진 칸을 글자 크기에 따라 줄이지 않는다.

### 하단 고정 이전·다음 바 (StepGuideScreen bottomNavigationBar)
- **용도:** S02에서 한 손으로 단계 이동. S02에는 하단 메뉴 대신 이 바가 있다.
- **모양:** surface 바탕, 위 divider 선, 안전 영역 위. 단계 화면 '이전'(보조) : '다음'(경로색) = 1 : 1.4. 완료 화면 '경로 목록으로'(보조) : 'n단계 다시 보기'(경로색) = 1 : 1.
- **상태:** 첫 단계 '이전' 누를 수 없음 / 마지막 단계 '다음' → '승강장에 왔어요' / 단계를 불러오는 중·실패면 바 없음 / 큰 글자면 본문 끝으로(S02 명세).
- **하지 말 것:** S03·S04·S07에 고정 바를 두지 않는다(버튼은 본문 끝).

## 4. 목록 카드

### 경로 카드 (_RouteCard)
- **용도:** S01에서 경로 고르기.
- **모양:** surfaceContainer, radii.card, 최소 높이 88. 왼쪽 띠 8(직통 routeExpress, 일반 routeLocal, 준비 중 outline), 이름 typography.routeName, 한 줄 설명(support), 표지판 병기 줄(caption), 오른쪽 숫자.
- **변형:** 시작 전 'N 단계' / 진행 중 '(현재)/N 이어 보기' / 끝까지 봄 'N/N 완료' / T2 준비 중('준비 중' 배지, 숫자 없음).
- **동작:** 누르면 S02(기억한 단계). T2는 하단 알림 'T2 안내는 준비 중입니다'만. 진행이 있으면 카드 아래 '처음부터'.
- **접근성:** 카드 하나가 버튼 하나로 읽힌다. 숫자는 '5단계 중 3단계, 이어 보기'처럼 읽는다.
- **하지 말 것:** T2를 회색 '누를 수 없음'으로 만들지 않는다. 경로를 색만으로 구분하지 않는다.

### 팁 카드 (TipCard)
- **용도:** S02 팁 영역, S06 내 팁.
- **모양:** surfaceContainer, radii.box, 안쪽 여백 가로 14 세로 12. 제목(700) + 배지, 메모(support), '위치 · 작성자'(caption). S06은 맨 위에 '직통열차 · 5단계 중 3단계'(small), 작성자 대신 '이 단계 보기'.
- **작성자:** 예시 팁 'Sample / 샘플', 내 팁 'by you / 내가 올림', 다른 사람 팁 'by a traveler / 여행객'.
- **상태:** 기본 / 방금 올림(primary 2 테두리 1.8초) / 저장 중(그 카드만 '저장 중…') / 실패(카드 안 빨간 알림 + 다시 시도) / 권한 없음(카드 안 노란 알림 + 다시 로그인, 버튼 막힘).
- **동작:** 상태 바꾸기는 내가 올린 팁(서버 mine)에만. 예시 팁은 올린 사람이어도 숨긴다. 정보 오래됨 팁은 '지난 팁 n개 보기' 아래로 접는다.
- **긴 글:** 제목(80자)·위치(80자)·메모(150자)는 자르지 않고 모두 보인다. 제목과 배지가 한 줄에 안 들어가면 배지가 다음 줄로 간다.
- **하지 말 것:** 알림을 팁 영역 맨 위에 모으지 않는다(어느 팁인지 모름). 다른 사람 팁에 상태 버튼을 보이지 않는다.

### 상태 배지 (Pill / TipStatusPill)
- **용도:** 팁 상태와 경로 준비 상태.
- **모양:** 알약(radii.chip), 안쪽 여백 가로 8 세로 3, typography.badge.
- **변형:**
  - 작성자 확인: 'Checked by author · 2026-10-20 / 작성자 확인 · 2026-10-20' — statusSurface · statusText
  - 오래됨: 'Marked out of date by author · 날짜 / 작성자가 오래됨 표시 · 날짜' — warningSurface · warningText
  - 예시: 'Example / 예시' 채움 — textSecondary 바탕 · surface 글자. 예시 팁은 이 배지 하나만
  - 준비 중: 'Coming soon / 준비 중' — warningSurface · warningText
- **날짜:** verifiedAt(작성자가 마지막으로 상태를 정한 시각)의 서울 날짜.
- **접근성:** 색과 문구를 함께 쓴다. 팁 상태 배지는 바뀌면 낭독한다.
- **하지 말 것:** '확인됨'처럼 누가 확인했는지 없는 문구를 쓰지 않는다. 예시 배지를 테두리만으로 만들지 않는다.

## 5. 알림과 상태

### 화면 안 알림 상자 (NoticeBox)
- **용도:** 화면에 남아야 하는 실패와 다음 행동.
- **변형:** 오류(errorSurface · error): 팁 못 불러옴, 상태 못 바꿈, 올리기 실패, 로그인 끝남, 로그인 실패. 경고(warningSurface · warningText): 권한 없음.
- **모양:** radii.box, 글자 support, 아래에 글자 버튼(다시 시도 / 다시 로그인).
- **접근성:** 나타나면 낭독한다.
- **하지 말 것:** 원인을 모르는 실패에 '인터넷 연결'을 단정하지 않는다.

### 하단 알림 (SnackBar, AppController.showMessage)
- **용도:** 끝난 일을 잠깐 알림. 'Tip posted / 팁을 올렸습니다', 'T2 안내는 준비 중입니다', 'Logged out / 로그아웃했습니다', 화면을 떠난 뒤 끝난 실패.
- **모양:** 떠 있는 상자, textPrimary 바탕, surface 글자 16 / 700, radii.box.
- **시간:** 3초. 새 알림은 앞 알림을 닫고 뜬다.
- **동작:** 화면을 쌓거나 닫을 때, 하단 메뉴로 탭을 바꿀 때 닫는다. 화면을 옮기는 경우에는 옮긴 뒤에 띄운다.
- **하지 말 것:** 다시 시도가 필요한 실패를 하단 알림만으로 알리지 않는다(화면 안 알림 상자를 쓴다).

### 가운데 안내 (StatusMessage)
- **용도:** 화면 전체가 비었거나 실패했을 때, 로그인이 필요할 때.
- **모양:** 아이콘 없이 제목(typography.statusTitle) · 설명(textSecondary) · 주요 버튼, 가운데 정렬. 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 연결 끊김만 제목 위에 그림(OfflineIllustration: surfaceContainer 원 112 · 와이파이 끊김 아이콘 56 textSecondary · 오른쪽 아래 warningSurface 원 안 비행기 아이콘 22 warningText, 낭독에서 뺌)을 두고 버튼 아래 한 줄(14, textSecondary)을 더한다.
- **변형:** 연결 끊김(그림 + 공항 무료 와이파이 안내 + 다시 시도 + 'If airplane mode is on, turn it off. We'll load this automatically when you're back online. / 비행기 모드라면 꺼 주세요. 인터넷이 다시 연결되면 자동으로 불러와요.'), 원인 모를 실패('Couldn't load this. Try again. / 불러오지 못했어요. 다시 시도하세요.' + 다시 시도), 빈 경로, 빈 내 팁, S06 로그인 필요(+ 로그인).
- **자동 다시 읽기(현재 동작(고도화, 위젯 검사 통과·화면 대조 전)):** 연결 끊김 안내가 떠 있는 동안(S01·S02 단계·S06) 3초마다, 앱으로 돌아올 때(resumed) 바로 안내를 둔 채 다시 읽고(AutoRetry), 앞 요청이 끝나기 전에는 다시 보내지 않는다. 다시 붙는 도중 다른 실패(시간 초과·서버)가 나면 그 안내를 보이되 계속 다시 읽는다. 처음부터 다른 실패면 자동으로 보내지 않는다. 새 권한 없이(INTERNET만) 요청 결과로 판단한다.
- **하지 말 것:** 빈 목록과 실패를 같은 문구로 쓰지 않는다.

### 불러오는 중 자리표시 (SkeletonBox)
- **용도:** 불러오는 동안 자리 잡기.
- **모양:** surfaceContainer 상자. 경로 카드 88 × 3, 사진 4:3, 팁 56, 내 팁 120 × 2. 반짝임 없음.
- **접근성:** 자리표시는 낭독에서 빼고, 문구 한 줄('Loading routes… / 경로를 불러오는 중…' 등)이 상태를 알린다.
- **현재 동작(고도화, 위젯 검사 통과·화면 대조 전):** S06에도 문구 한 줄을 둔다('Loading your tips… / 내 팁을 불러오는 중…'). 불러오는 중 화면(S01, S02 단계·팁, S06)은 8초가 지나도 응답이 없으면 문구 아래 'Slow connection. Check the airport Wi-Fi. / 연결이 느려요. 공항 와이파이를 확인하세요.'를 더한다. 15초가 지나면 원인 모를 실패 안내로 바꾼다(10장).

### 확인창 (AlertDialog, S03)
- **용도:** 되돌릴 수 없는 입력 손실 하나. S03에서 하나라도 입력한 채 취소·뒤로를 누를 때.
- **모양:** surface 바탕, radii.dialog. 제목 'Discard this tip? / 작성 중인 팁을 버릴까요?', 본문 'What you typed will be lost. / 입력한 내용이 사라집니다.' 버튼 '버리기'(보조, 왼쪽) : '계속 쓰기'(주요, 오른쪽) = 1 : 1.4.
- **동작:** 처음 초점은 '계속 쓰기'. 바깥 누름·시스템 뒤로도 '계속 쓰기'. 올리는 중에는 확인 없이 나간다.
- **하지 말 것:** 로그아웃, 테마·언어 바꾸기, 상태 바꾸기, S04 취소에 확인창을 쓰지 않는다. 위험한 쪽('버리기')을 주요 버튼으로 두지 않는다.

## 6. 최상위 화면 부품

### 하단 메뉴 (FloatingTabBar, HomeShell)
- **용도:** 최상위 화면 사이 이동. 경로(S01) / 내 팁(S06) / 설정(S05).
- **모양(현재 동작(고도화, 위젯 검사 통과·화면 대조 전)):** 화면 아래 떠 있는 둥근 캡슐(2026-10-22 사용자 요청 D14로 예전 화면 폭 NavigationBar 막대를 바꿈). 좌우 spacing.page·아래 spacing.card를 띄우고(안전 영역 위), surface 바탕·divider 테두리·radii.chip·그림자(검정 12%·흐림 18·아래 4), 최소 높이 sizes.navBarHeight(68), 안쪽 spacing.fieldGap. 탭마다 아이콘 + 글자(typography.navLabel). 선택한 탭은 surfaceContainer 둥근 선택 칸과 채운 아이콘, 아이콘·글자 textPrimary 700. 나머지는 outlined 아이콘, textSecondary 500. 글자를 키우면 캡슐도 높아진다.
- **보이는 곳:** S01·S06·S05에서만. S02~S04·S07은 그 위에 쌓여 메뉴가 없다. 메뉴가 보이는 화면에는 뒤로 가기 버튼이 없다.
- **동작:**
  - 다른 탭 누름: 그 화면으로 바뀌고 하단 알림을 닫는다(현재 동작). 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 아이콘·글자는 바로 바뀌고, 선택 칸 하나가 새 탭으로 늘어나며 미끄러진다(350ms, 앞쪽 끝 easeOutCubic·뒤쪽 끝 easeInOutCubic, D15).
  - 끌기: 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 캡슐 위를 좌우로 끌면 선택 칸이 손가락을 따라가고, 손을 떼면 칸 가운데가 가장 가까운 탭으로 바뀐다. 원래 탭이면 그대로 두고 맨 위로 올리지 않는다(D15).
  - 같은 탭 다시 누름: 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 그 화면을 맨 위로 스크롤한다(250ms, 동작 줄이기 설정이면 바로).
  - 시스템 뒤로: S05·S06 → 경로 탭, 경로 탭 → 앱 닫힘(현재 동작).
  - 탭을 오갈 때: 테마·언어·로그인·진행은 그대로. S01은 보관한 경로 목록을 다시 쓰고, S06은 들어올 때마다 다시 읽는다. 스크롤은 맨 위부터(현재 동작).
- **누름 표시(현재 동작(고도화, 위젯 검사 통과·화면 대조 전)):** 누를 때 물결·눌림 색이 없다(지금 탭은 선택 칸으로 구분, D15). 키보드 초점 표시는 남긴다.
- **접근성:** 탭마다 이름과 순서('Routes / Tab 1 of 3')를 한 버튼으로 읽고 현재 탭은 선택 상태로 읽힌다. 끌기는 낭독에서 빼고 탭 버튼만 읽힌다. 탭을 바꾸면 상단 바 제목에 초점(S01은 본문 제목). 동작 줄이기면 선택 칸을 바로 옮긴다.
- **하지 말 것:** S02~S04·S07에 메뉴를 보이지 않는다. 메뉴에 언어·테마 버튼을 넣지 않는다. 탭 글자를 빼고 아이콘만 두지 않는다(여행객이 뜻을 바로 알도록, D14).

### 설정 선택칸 (_ThemeOption, _LanguageOption)
- **용도:** S05 화면 테마와 언어. 테마·언어는 여기서만 바꾼다.
- **변형:** 테마 3칸(System / Light / Dark = 시스템 / 밝게 / 어둡게, 칸 최소 48), 언어 두 줄(English EN / 한국어 KO, 줄 최소 56, 그 언어로 표기, 국기 없음).
- **상태:** 선택 = primary 2 테두리 + 체크(두 칸 모두 같은 표시).
- **동작:** 누르면 바로 적용하고 기기에 기억한다.
- **접근성:** 테마 칸은 셋 중 하나만 고르는 라디오, 언어 줄은 선택 상태가 있는 버튼으로 읽힌다.
- **하지 말 것:** 지구본 버튼이나 다른 화면의 언어 토글을 만들지 않는다.

### 단계 요약 줄 (StepSummary, S03)
- **용도:** 어느 경로·단계에 팁을 올리는지 보여 줌.
- **모양:** surfaceContainer, radii.box, 왼쪽 경로색 띠 6, 머리말 'STEP / 단계', '직통열차 · 5단계 중 3단계 — 단계 제목'.
- **하지 말 것:** 입력칸처럼 테두리를 두지 않는다(고를 수 없는 값).

## 7. 공통 규칙

- **화면 제목 초점(FocusHeading):** 화면이 열리면 초점을 화면 제목으로 옮긴다. S02 단계 제목은 'Step n of N: 제목'으로 읽고 단계가 바뀌면 다시 읽는다.
- **스크롤:** 본문은 세로 스크롤 하나(ScrollColumn). 지연 생성 목록을 쓰지 않는다(스크롤로 제목이 다시 만들어져 초점을 빼앗지 않게).
- **큰 글자:** 글자 확대를 막지 않고 고정 높이에 잘라 넣지 않는다. 줄이 넘치면 Wrap으로 다음 줄로 보낸다. S02의 조건 숫자는 S02 명세.
- **상단 바(AppBar, appBarTheme):** 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 화면 바탕과 같은 surface, 제목 typography.appBarTitle(21 / 700) textPrimary 가운데 정렬, 그림자 없음(스크롤해도 그대로). 상태 표시줄 아이콘은 밝은 테마에서 어둡게, 어두운 테마에서 밝게. 하위 화면(S02·S03·S04·S07)은 왼쪽 뒤로 가기. 남색(signage)은 표지판 칩에만 쓴다(2026-10-22 사용자 요청 D14).
- **동작 줄이기:** 사진 넘김은 바로 바뀐다. 현재 동작(고도화, 위젯 검사 통과·화면 대조 전): 새 팁으로 스크롤, 단계 이동 뒤 맨 위로, 같은 탭 다시 누름도 바로 이동한다. 사진을 밀 때도 돌리지 않고 평평하게 넘기며, 하단 메뉴 선택 칸은 바로 옮긴다.
- **시간:** 하단 알림 3초, 사진 넘김 250ms, 하단 메뉴 선택 칸 350ms(현재 동작(고도화, 위젯 검사 통과·화면 대조 전)), 새 팁 스크롤 300ms와 강조 1.8초, 카드 테두리 변화 200ms, 화면 전환은 플랫폼 기본.
- **장식 금지:** 시안의 휴대폰 테두리, 오른쪽 검토 패널, 상태 미리보기 버튼은 앱에 넣지 않는다.

## 화면별로 함께 읽을 문서

화면의 요소·상태·문구·이동은 S02~S06-screen-spec.md를 따릅니다. 이 문서는 여러 화면에서 같은 부품을 같은 모양으로 쓰기 위한 규칙입니다. 서버와 주고받는 이름은 ui-handoff.md와 서버 docs/api-spec.yaml을 봅니다.
