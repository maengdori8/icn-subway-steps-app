로그인·등록·상태 변경은 시안 동작이며 실제 서버에 저장되지 않습니다. 경로별 진행 단계와 테마만 이 브라우저에 기억합니다. 표지판 문구·엘리베이터 위치는 현장 확인 전 초안이고, 팁 내용은 시연용 가상 데이터입니다.

이번 버전에서 바뀐 것

설정(S05): 화면 테마·언어·계정·사진 출처. 상단 지구본 언어 버튼은 유지 S02: 이전·다음 하단 고정, 사진 가로 스와이프, 전체 단계 펼치기, 경로별 진행 기억 표지판 칩: 역할 라벨·픽토그램·큰 글자, 1단계 Terminal 1 표기 끝: '승강장에 왔어요' → 완료 화면 '5단계 다시 보기' 팁: 메모 저장·표시, 작성자 확인+날짜, 오래된 팁 접기, 상태 6가지 입력: 언어를 바꿔도 값 유지, 칸별 오류, 작성 중 나가기 확인
