## 기각된 지적

- **DEC-04(2단계 엘리베이터 문구):** 사용자 결정은 '단계마다 엘리베이터 자리를 두고 확인 필요 표시'이고, v03은 503행에서 그대로 지켰습니다. 2단계의 'escalator or elevator down one floor'는 일반 안내이고, 층수는 현장 확인 대상이라 결정과 어긋나지 않습니다.

반박 검증에서 하위 주장만 걸러 낸 경우는 다음과 같습니다.
- **VIS-02:** 1단계 주 칩을 '공항철도'로 바꾸자는 안은 결정 3(1단계 칩 = Terminal 1 Arrivals)과 충돌해 뺐습니다. 방향 화살표가 없는 것은 현장 확인 전이라 타당합니다.
- **VIS-04:** 완료 화면에 체크리스트를 넣고 승강장 칩을 반복하자는 안은 사용자 결정('승차권 보관 한 줄')과 어긋나 뺐습니다. '← Step 5 again'을 오른쪽에 둔 것은 결정 2대로입니다.
- **VIS-09:** S05에 지구본 버튼이 남은 것은 의도된 결정(언어는 상단과 설정 양쪽)입니다.
- **REG-03:** '다시 시도하면 보이지 않는 팁의 상태가 바뀐다'는 시안에서 성립하지 않습니다. 다시 시도해도 다시 실패할 뿐입니다.
- **A11Y-04:** 사진 대체 문구와 칩이 같은 내용을 두 번 읽는 문제는 3차 A11Y-9에서 이미 권고 수준으로 기각했습니다.
- **A11Y-08:** 확인창을 닫은 뒤 초점이 제목 칸으로 가는 것은 '계속 쓰기' 흐름상 허용 범위입니다.
- **DEC-03:** 실패·권한 없음(role=alert)과 로그아웃(toast)은 이미 알림이 있습니다.
- **REG-05:** 시안에는 안전 영역이 없어(0) 토스트가 '다음' 버튼을 덮지 않습니다.
- **DEC-07:** '큰 글자 규칙이 어디에도 없다'는 과장입니다. DS:189·232에 일반 규칙이 있습니다.
- **VIS-10:** 'Start over'가 어느 카드 것인지 애매하다는 주장은 과장입니다. 위 카드와 2px 거리라 위 카드에 붙어 보입니다.
